# ServerGuys brand assets

All files are made from the master logo `ServerGuys_Dark.png` (1472×322, transparent). Use these raw URLs in apps:
`https://raw.githubusercontent.com/ServerGuys-us/media/main/brand/<file>`

| File | Size | Use |
|---|---|---|
| `ServerGuys_Dark.png` | 1472×322 | Full logo, navy wordmark: **light backgrounds** (login pages, light headers, loading screens) |
| `ServerGuys_Light.png` | 1472×322 | Full logo, white wordmark: **dark backgrounds** (dark sidebars/headers, dark mode) |
| `ServerGuys_Mark_512.png` | 512×512 | Icon only (the `>_` terminal): app icons, avatars, social |
| `ServerGuys_Mark_180.png` | 180×180 | Apple touch icon, small app tiles |
| `ServerGuys_Mark_64.png` | 64×64 | Compact header mark |
| `ServerGuys_Favicon_32.png` | 32×32 | Browser favicon (PNG) |
| `favicon.ico` | 16–64 | Browser favicon (ICO, multi-size) |

Notes
- `ServerGuys_Light.png` is the master with only the wordmark recolored white; the icon is unchanged.
- The icon files are the master's icon cropped onto a transparent square.
- The older `ServerGuys_Dark.svg` and `terminal*.png` in the repo root are approximations, not the master logo. Don't use them for new work.
- Apps using these (2026-11-02): authentik (auth.serverguys.us), Wazuh dashboard (siem.serverguys.us).
